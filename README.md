# Data Acquisition Project
Exploratory analysis of 30 recently active Stack Overflow questions, pulled live from the Stack Exchange API.
## What I did
- Retrieved JSON data with Python's `requests` library
- Cleaned the data in pandas (dropped sparse columns, flattened nested fields, removed duplicates)
- Built visualizations with Seaborn and Matplotlib to answer six questions about answer rates, licensing, tags, and score

## Tools
Python, pandas, NumPy, Seaborn, Matplotlib
